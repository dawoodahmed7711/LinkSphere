# 🔗 LinkSphere

**LinkSphere** is a customizable link-in-bio web application that allows users to create their own personalized profile page and share all their important links in one place.

Customize your profile, choose themes, style your text, and preview your page in a mobile-style layout.

## ✨ Features

- 👤 **Personalized Profile** — Add your profile image, name, and bio.
- 🔗 **Link Management** — Add and manage links in one place.
- 🎨 **Custom Themes** — Customize background and button styles.
- ✍️ **Text Customization** — Change text colors, fonts, and decorations.
- 🪄 **Hover Effects** — Add interactive hover effects to your buttons.
- 📱 **Live Mobile Preview** — Preview your profile page while customizing it.
- 🔐 **Authentication UI** — Sign up and log in to access your dashboard.
- 📊 **Dashboard** — Manage your profile and customization settings.

## 🛠️ Tech Stack

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- React Context API
- Browser Local Storage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd link-sphere-linkbuilder
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit [http://localhost:3000](http://localhost:3000) to view the application.

## 📁 Project Highlights

- Component-based architecture
- Reusable React components
- State management using Context API
- Responsive dashboard interface
- Dynamic profile customization
- Interactive mobile preview

## 🎯 Project Goal

The goal of LinkSphere is to provide a simple and user-friendly way for people to create a personalized page for sharing their social media profiles, websites, portfolios, and other important links.
